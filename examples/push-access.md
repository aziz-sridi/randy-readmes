# Push Access

Randy presses git push, scatters the contribution calendar, falls, gets back up, and holds a “Works on my machine” sign. The real calendar rebuilds before the 20-second loop repeats.

Copy both SVGs into your profile repository's `dist/` folder, then paste:

```html

  <img src="./dist/push-access.svg" width="900" alt="Randy presses git push, scatters the calendar, falls, and gets back up." />
</picture>
```
